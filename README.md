# Sri Parvathi Metals — website

Live at **https://sreeparvathimetals.com** (hosted on GitHub Pages).

## Files

| File | What it holds |
|---|---|
| `index.html` | All the page content and text, split into clearly marked sections |
| `css/base.css` | Colors, fonts, backgrounds, buttons, cards |
| `css/animations.css` | Every animation (slideshow, sparkles, shimmer, casting pour) |
| `css/photos.css` | How photos are shown |
| `css/responsive.css` | Phone layout, scroll effects, reduced-motion |
| `js/main.js` | Small helpers (photo fallback, footer year) |
| `images/` | Your own photos go here |
| `CNAME` | Connects the custom domain — **do not delete** |

## Editing text

Open `index.html`, search (Cmd+F) for the text you want to change, edit only the words
between the tags, save, then in GitHub Desktop: **Commit to main** → **Push origin**.
The live site updates in 1–2 minutes.
